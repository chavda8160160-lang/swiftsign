# SwiftSign Android Project 📱

This is the native Android project for **SwiftSign**.

## How to Open in Android Studio:
1. Open **Android Studio**.
2. Click **Open** (or `File > Open...`).
3. Select this folder: `D:\Yogesh\Personal\New folder (2)\android`
4. Wait for Gradle Sync to complete.

## How to Run:
- **Terminal:** Run `.\gradlew.bat installDebug`
- **Android Studio:** Click the green **Run ▶** button in the toolbar.
- **Generate Standalone APK:** `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
